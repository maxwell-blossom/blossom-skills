# Blossom Skills — V1 prototype (Greg, Nov 7 2026)

Live: https://blossom-skills.netlify.app (Netlify site `blossom-skills`, id fbc4d7b7-a267-451a-95a9-8c10121f0dd8).

Build: `bash build.sh` → unpacks `assets.tgz.b64` into `assets/`, runs `python3 build.py` (→ `index.html` single-page app with hash routes + `skills/<slug>/SKILL.md` served for the curl installs) and assembles `dist/` (`index.html`, `skills/`, `shots/`, `og.jpg`). Netlify builds from this repo via `netlify.toml`. See CONTRIBUTING.md.

Catalogue and creators: `data.py`. Creators other than @blossom, @beevis, @maxstocks are invented. Downloads, ratings and reviews are seed numbers. `gen_shots.py` renders the sample-output screenshots (Blossom-styled widgets, Playwright); `gen_og.py` renders the share-card image.

Decisions (Max, Nov 7): the page is framed as a tab inside the Blossom web app (sidebar with "Skills & MCPs" beside Chat with Beevis, real app icons from blossomsocial.com; logged-out top bar); skills only can be posted — MCPs are listed by Blossom and partners; broker MCPs (Public, Questrade, Robinhood) are not listed on the MCPs tab, skills declare them under "Also supports"; required MCPs under "What it needs"; sample outputs are screenshots first (gallery + lightbox, first one on the card), text sample collapsed; creators can upload up to 4 screenshots; a skill can declare "⚠️ can place orders" (badge on card and listing); pricing = free / one-time / monthly / yearly, **no free trials**; Blossom take 20%; Blossom Aggregate Trade Data MCP is paid ($19/mo · $149/yr, no free tier); install tabs = Claude, Claude Code, Cursor, ChatGPT, Grok (Grok takes remote MCPs at grok.com/connectors → Custom; no skill files, so the tab says paste the SKILL.md as the first message); tagline "Built by verified investors on Blossom"; Connector MCP reads posts too (get_feed, get_ticker_posts, search_posts, get_post, get_my_posts).

Stripe: `PAYLINKS` at the top of the JS in build.py — one Payment Link (sandbox/test mode) per paid plan. null = the mock checkout opens. A real link gets `?client_reference_id=<handle>:<skill>:<plan>`; the Payment Link's after-payment redirect is `https://blossom-skills.netlify.app/?checkout=success&skill=<id>&plan=<plan>` and the page records the purchase and shows the install screen. Wired so far: `dividend-income-planner` monthly (test link). To add the rest: Stripe sandbox → Payment links → New → product + recurring price → After payment → "Don't show confirmation page" → the redirect above → Create link → paste into PAYLINKS → rebuild. Real unlock (server-side session check) needs `STRIPE_SECRET_KEY` in Netlify env — not committed here.

What is mocked: login (you are @maxstocks), review queue, Stripe Connect onboarding, comments/ratings composer, follower counts, entitlement checks (a skill is a text file; real gating lives in the Blossom MCP). Everything the user clicks works end to end in the browser; "my" skills and purchases persist in localStorage.
